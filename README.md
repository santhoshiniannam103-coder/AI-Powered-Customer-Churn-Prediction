# AI-Powered Customer Churn Prediction

## 📌 Project Overview

This project is an AI-powered customer churn prediction solution that uses machine learning to identify customers who are likely to churn and classify customers into different risk levels.

The project combines Python, machine learning, XGBoost, and Power BI to provide predictive insights and an interactive customer churn dashboard.

## 🎯 Objectives

- Predict customer churn using machine learning models.
- Compare the performance of multiple ML algorithms.
- Identify high-risk customers.
- Analyze churn patterns based on customer characteristics.
- Provide actionable customer retention recommendations.

## 🤖 Machine Learning Models

The following models were evaluated:

- Logistic Regression — 71.35%
- Random Forest — 76.28%
- XGBoost — 78.91%
- Tuned XGBoost — 80.77%

**Best Performing Model: Tuned XGBoost — 80.77% Accuracy**

## 📊 Power BI Dashboard

The interactive dashboard provides:

- Total Customers
- Churned Customers
- Churn Rate
- AI Model Accuracy
- Average Monthly Charges
- Churn Rate by Contract
- Churn Rate by Risk Level
- AI Risk Distribution
- Model Performance Comparison
- Key Insights and Retention Recommendations

## 🔍 Key Insights

- Month-to-month customers have the highest churn rate: **42.71%**
- High-risk customers have an **82.4% churn rate**
- Two-year contract customers have the lowest churn rate: **2.83%**
- **8.4%** of customers are classified as high risk by the AI model.

## 💡 Recommendation

Prioritize high-risk, month-to-month customers with targeted retention offers.
